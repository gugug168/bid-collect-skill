# 城市入口索引（CITY_ENTRY_INDEX）

> Goal v2 配套（2026-08-15）。范围：**zb 阶段 16 列 + 城市入口**；B阶段 暂缓。
> 记录 `province-collect.cjs` 的 `-c/--city` 城市筛选机制在 32 省的现状与逐省入口能力。

## 机制总览

1. **客户端 OR 过滤**（全部 32 省可用）：`matchesCityFilter`（L3534）对「列表地区 / 标题 / 提取城市」三源取 OR；
   仅当用户显式传 `-c <城市>` 时排除不匹配记录，不传则全省。支持多值 `,、` 分隔（OR）。
2. **真实逐城市 URL 路由**：仅 **广东（粤公平）** 实现——`GD_CITIES`（21 地市），因省级 `siteCode=440000` 返回 0，
   须逐地市循环聚合才得全省。其余 31 省均为「全省列表 + 客户端过滤」，平台不暴露独立城市列表接口（或未知）。
3. **城市抽取粒度**：`pickCity`（L2042，取列表字段 zhuanzai/xiaquname/fieldvalue/infod）+ `extractCity`（L3509，
   取标题【】或起首行政区）提供 **区县/地市** 级粒度，足以支撑 `-c` 过滤。

## 诚实口径

- “逐城市 URL 路由”仅 GD 落地；其他省靠客户端过滤即可满足「按城市取数」，差异仅是**抓取量**（全省列表后过滤 vs 直取该城市接口）。
- 把 31 省逐一接「逐城市 URL」需各省 city code 表 + 列表 URL 模板（per-platform 精修），属后续专项，**本轮未做**，不伪造。
- 城市抽取偶见脏值（verbose projectSite 落入 city）→ 已由 L3758 守卫修复（仅短地名回填）。
